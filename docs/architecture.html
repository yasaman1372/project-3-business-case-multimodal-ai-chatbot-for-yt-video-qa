INDEXING PIPELINE

Runs locally (ingestion/build_index.py) and live when the agent adds videos on a new topic
▶

Find Videos by Topic

YouTube Data API v3 search · filter 3–40 min · skip already indexed

ingestion/find_videos.py → videos.txt
1

Load Transcripts

youtube-transcript-api: captions with start times · cached as JSON · failed videos skipped

ingestion/youtube_loader.py → data/transcripts/
2

Preprocess

Remove caption noise ([music], ♪, >>) and extra whitespace; keep timestamps. No lowercasing / lemmatization: embeddings work best on natural text

ingestion/preprocess.py → data/processed/
3

Chunk

~250 words (max 350), end at sentence boundary, 50-word overlap · LangChain Documents with stable IDs videoId_n

ingestion/chunking.py
4

Embeddings

OpenAI text-embedding-3-small · 1536 dimensions · same model for indexing and queries

ingestion/embeddings.py
5

Store in Pinecone

Serverless index (AWS us-east-1, cosine) · upsert by ID, so re-indexing never duplicates

ingestion/vector_store.py

Metadata stored with each chunk

video_idtitlechanneltopicurllanguagechunk_indexstartendtimestamptimestamp_urlword_count
